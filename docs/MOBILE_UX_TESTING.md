# Mobile UX 測試驗證指南

## 🎯 測試目標

驗證手機版（<1024px）與桌面版（≥1024px）的表單體驗：
- 手機版：舒適、不擠、易點擊
- 桌面版：完全不變（零改動）

---

## 📱 手機測試 (< 1024px)

### Chrome DevTools 模擬測試

```bash
1. 開啟 https://www.jobbeagle.com
2. F12 開啟 DevTools
3. 點擊 Toggle Device Toolbar (Ctrl+Shift+M)
4. 選擇 "iPhone 14 Pro" (393×852)
5. 硬重新整理 (Ctrl+Shift+R)
```

### ✅ 檢查清單

#### 整體版面
- [ ] **無橫向滾動**：左右不需滑動
- [ ] **首屏高度合理**：表單完整可見，不需狂滾
- [ ] **間距舒適**：元素之間有呼吸空間，不會緊貼

#### 文字可讀性
- [ ] **Logo 大小適中**：不會太大或太小
- [ ] **描述文字清晰**：不需放大即可閱讀
- [ ] **步驟標題清楚**：1. 職缺資訊、2. 我的履歷、3. 選擇報告類型

#### 觸控體驗
- [ ] **按鈕容易點擊**：不會誤觸其他元素
- [ ] **上傳區域明顯**：清楚知道可以點哪裡
- [ ] **Launch 按鈕突出**：最終提交按鈕清楚可見

#### 功能驗證
- [ ] **貼上 JD**：SmartInputArea 正常運作
- [ ] **上傳履歷**：PDF/Word/Text 都可以上傳
- [ ] **選擇報告類型**：Snapshot / Strategy Guide 切換正常
- [ ] **提交表單**：點擊 Launch 後進入 loading 狀態

---

## 💻 桌面測試 (≥ 1024px)

### 測試步驟

```bash
1. 開啟 https://www.jobbeagle.com
2. 調整瀏覽器寬度 ≥ 1024px
3. 硬重新整理 (Ctrl+Shift+R)
```

### ✅ 檢查清單

#### 與之前完全一致
- [ ] **4步驟並列**：Job | Resume | Report Type | Launch 橫向排列
- [ ] **Feature cards 顯示**：4個功能卡片 hover 展開
- [ ] **步驟箭頭**：→ 箭頭在步驟之間顯示
- [ ] **卡片高度對齊**：4個步驟底部對齊

#### 無任何視覺差異
- [ ] **字體大小**：與之前相同
- [ ] **間距**：與之前相同
- [ ] **顏色**：與之前相同
- [ ] **動畫**：與之前相同

---

## 🔄 斷點切換測試

### 測試 lg (1024px) 斷點

```bash
1. 開啟瀏覽器寬度 1100px (桌面版)
2. 慢慢縮小寬度到 1020px
3. 觀察版面是否切換到手機版
4. 再放大回 1100px
5. 觀察版面是否切換回桌面版
```

### ✅ 檢查清單
- [ ] **切換平滑**：無閃爍或跳動
- [ ] **資料保留**：填寫的內容不會消失
- [ ] **無 console 錯誤**：F12 檢查無紅色錯誤


- Performance: ≥ 80
- Accessibility: ≥ 90
- Best Practices: ≥ 90

## 🐛 已知問題 & 限制

### 預期行為
1. **Feature cards 在手機版隱藏**：節省空間，產品決策
2. **Resume history dropdown 在手機版較窄**：符合螢幕寬度
3. **字體在手機版固定大小**：不使用響應式縮放

### 不是 Bug
- 手機版沒有 hover 效果（觸控裝置無 hover）
- 手機版間距較小（符合設計規範）
- 桌面版與之前完全一致（刻意保持不變）

# JobBeagle 常見問題 (FAQ)

> 更新日期：2026-08-29

## 💰 付費與訂閱

### Q1: 如何付款？
**A:** 我們使用 PayPal 作為支付平台，接受：
- PayPal 帳戶
- 信用卡 / 簽帳卡（PayPal 結帳頁）

### Q2: 可以隨時取消訂閱嗎？
**A:** 可以！
- 登入後前往 `/account` 頁面
- 點擊「Cancel subscription」一鍵取消
- 你的會員權益會保留到當期結束
- 不會再自動續訂

### Q3: 取消後額度會消失嗎？
**A:** 不會！
- 當期剩餘額度會保留到訂閱結束日
- 例如：8/15 取消 $19.99/月訂閱，9/15 到期前都還能用

### Q4: 有退款政策嗎？
**A:** 
- 單次購買：購買後 14 天內可申請退款（未使用額度）
- 訂閱制：首次訂閱 14 天內可申請退款
- 請聯絡 support@jobbeagle.com

### Q5: 發票在哪裡？
**A:** 
- 購買後會收到 PayPal 寄送的收據 Email
- 或前往 `/account` → 點擊「Manage billing」→ 查看所有發票

## 🔐 帳戶與隱私

### Q6: 需要註冊帳號嗎？
**A:** 是的，使用前需要登入：
- Google 帳號登入（推薦）
- GitHub 帳號登入

### Q7: 你們會儲存我的履歷嗎？
**A:** 不會長期儲存：
- 履歷僅用於當次分析
- 系統會在 **30 天後自動刪除**
- 不會分享給第三方

### Q8: 我的資料安全嗎？
**A:** 是的：
- ✅ 所有傳輸使用 HTTPS 加密
- ✅ 遵守 CCPA、GDPR 隱私規定
- ✅ 不販售個人資料
- ✅ 可隨時刪除所有資料

### Q9: 如何刪除帳戶？
**A:** 
- 前往 `/account/danger` 頁面
- 選擇「Permanently delete account」
- 系統會清除所有資料（履歷、報告、個人資訊）
- **注意：此操作無法復原**

- ✅ Glassdoor

### Q11: 外掛無法抓取怎麼辦？

2. 檢查外掛是否已啟用（工具列圖示應該是彩色的）
3. 改用「手動貼上 JD」方式（首頁直接貼上）

### Q12: 可以分析中文職缺嗎？
**A:** 可以，但建議：
- JobBeagle 主要針對**美國市場**優化
- 中文職缺也能分析，但準確度較低
- 建議使用英文履歷 + 英文 JD 獲得最佳結果

### Q13: 上傳履歷格式？
**A:** 支援：
- ✅ PDF（推薦）

**檔案大小限制：** 10MB

### Q14: 分析需要多久？
**A:**

- **Interview Strategy Guide：** 約 30-60 秒（需搜尋網路資料）

## 📊 報告內容

### Q15: Snapshot 和 Strategy Guide 差在哪？
**A:**

| 功能 | Job Fit Snapshot | Interview Strategy Guide |
|------|-----------------|-------------------------|
| 適配分數 | ✅ | ✅ |
| Apply Decision | ✅ | ✅ |
| 薪酬範圍 | 閉卷估算 | 開放式調查（含市場數據） |
| 公司背景 | ❌ | ✅ AI 搜尋最新動態 |
| 面試策略 | ❌ | ✅ 完整準備指南 |
| 引用來源 | ❌ | ✅ 所有來源標註 |
| 價格 | $3 | $9.99 |

**簡單說：**
- Snapshot = 快速篩選（適合海投）
- Strategy Guide = 深度準備（適合面試）

### Q16: 適配分數怎麼算的？
**A:** 綜合評估五大維度：
1. **Skills Match（技能匹配）**
2. **Experience Match（經驗匹配）**
3. **Career Fit（職涯適配）**
4. **Stability（穩定性）**
5. **Culture Fit（文化適配）**

**計分邏輯：**
- 0-49 分：Not a good fit（不建議投）
- 50-69 分：Moderate fit（可考慮）
- 70-100 分：Good/Great fit（建議投）

### Q17: 薪酬估算準確嗎？
**A:** 
- **Snapshot（閉卷估算）：** 基於 AI 模型的經驗推測，僅供參考
- **Strategy Guide（開放式調查）：** 會搜尋 Glassdoor、Levels.fyi 等公開數據，較準確

**注意：** 實際薪酬受公司規模、地點、談判能力等影響，報告僅供參考。

### Q18: 報告會過期嗎？
**A:** 
- 報告在你的帳戶內**永久保存**（除非你刪除帳戶）
- 可隨時在 `/account` 查看歷史報告

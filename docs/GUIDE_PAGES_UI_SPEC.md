# JobBeagle 報告範圍 — Excel 原稿（唯一真相來源）

來源檔：`Desktop/ Jobbeagle報告範圍.xlsx`（工作表1）。實作必須嚴格對齊下列 A–E，禁止自行加欄位或幻想內容。

## A｜求職者匹配度（Page 1 · Snapshot）

1. 綜合匹配分數與簡評：0–100 + 小狗圖等級 + 綜合評語  
2. 匹配強項與關鍵缺口：3–4 優點 + 3–4 缺口；明確硬技能/軟技能  
   - **ATS 淘汰預警**：顯示「ATS 通過預估率：42%（高風險被系統自動刷掉）」，標註缺少核心關鍵字數量  
3. 市場薪資落點預測：範圍/中位數 + 使用者落點  

LLM：輕量模型 / 低延遲。薪資可用預計算數據，不依賴高階 LLM。

## B｜職位與團隊現況（Page 2）

1. 職位內容/要求：用人看得懂的重點整理（「這份工作在做什麼」「錄取關鍵條件」），**嚴禁照抄 JD**  
2. 工作型態與 RTO：官方規定 + 真實體感（加班）  
3. 職涯：1–3 年下一職銜 + 能力缺口；**無公司內部職等表時，必須依 Levels.fyi／LinkedIn／就業市場報告等推估**，並標註依據（`career_path_basis`），不可留空  
4. **嚴禁任何具體薪資金額**  
5. 降級：該團隊無公開評價 → 同部門風向或標註「該團隊公開樣本不足」（僅限團隊文化／WLB；下一職銜仍走市場路徑）  

來源：LinkedIn, Glassdoor, Company Career Page, Levels.fyi / 就業市場報告（職涯階梯）。

## C｜公司真相與風險（Page 3）

1. **先寫公司現況**（`company_overview`）：產業／客群／階段／市場位置，讓求職者先知道「這是怎樣的一間公司」— 不是創業神話或維基沿革  
2. **公司最近發展**（`recent_developments`，最多 5 則）：經營層／重大產品／獲獎／融資等公開新聞；含標題、摘要、日期、分類、來源；**禁止編造 URL 或假新聞**；找不到可少於 5  
3. 公司現在在拚什麼（近期待辦／公開訊號，禁止輸出「非維基／百科」等 meta 用語）+ **2–3 家產業具名競爭對手**（搶市場的公司，禁止「BA 同儕」這類求職者桶）  
4. 內部人真實聲響（Glassdoor/Blind/Reddit）；小公司無貼文 →「公開論壇聲量較少」  
5. Layoff.fyi / 訴訟；無紀錄 →「無顯著公開違法/裁員紀錄」+ 2–3 戰略反問題  

來源：Reddit, X, Blind, Glassdoor, Layoff.fyi, SEC/新聞。

## D｜面試與談薪策略（Page 4）

1. 固定 **5 行為題 + 5 專業/案例題**；每題都要：考察意圖 + STAR + Do's & Don'ts（**預設全部展開顯示，勿用 hover／點擊才展開**）  
2. **找到的真題全部寫完整 STAR**（標「真題」），禁止「僅列出、不寫 STAR」的次要清單；每題 **分類標籤 + 編號 (1–5) + 完整來源**（站名／日期／可點 URL；無 URL 不編造；系統分析題標明非真題來源）  
3. 真題不足 5 題時，用系統分析最可能題目補滿（標「系統分析」）  
4. 薪資（與 Page 1 同三件）：**區間** + **座位中位數 (p50)** + **求職者落點預測**；其下再拆 TC：Base + RSU + Sign-on（Levels.fyi 等）  
5. 談薪：準備（錨定）→ Pitch → Counter  

## E｜參考資料與證據鏈（Page 5）

條列 RAG 原始連結；無 URL →「檢索數據摘要與建議手動查證關鍵字」，**絕不填充假網址**。

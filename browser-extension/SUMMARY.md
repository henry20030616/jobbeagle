## 🎯 使用流程

### 對於開發者

1. **本地測試**：
   ```bash
   # 1. 啟動開發伺服器
   npm run dev
   
   # 2. 修改 popup.js 為本地端點
   const WEBSITE_URL = 'http://localhost:3001';
   
   # 3. 在 Chrome 安裝插件
   # chrome://extensions/ → 開發人員模式 → 載入未封裝項目
   
   # 4. 測試 104/LinkedIn 職缺抓取
   ```

2. **生產部署**：
   ```bash
   # 1. 修改 popup.js 為正式網址
   const WEBSITE_URL = 'https://www.jobbeagle.com';
   
   # 2. 製作圖示（icon16.png, icon48.png, icon128.png）
   
   # 3. 重新載入插件並測試
   ```

### 對於用戶

1. **安裝插件**（參考 `QUICKSTART.md`）
2. **瀏覽職缺**（104 或 LinkedIn）
3. **點擊插件圖示** → 「抓取職缺並分析」
4. **自動跳轉到 JobBeagle**
5. **上傳履歷** → 開始分析

## 🔧 技術亮點

### 1. 無需後端 API

傳統方案通常需要：
```
插件 → API Server → 數據庫 → 前端讀取
```

我們的方案：
```
插件 → URL 參數/localStorage → 前端直接讀取
```

**優勢**：
- 減少伺服器負載
- 降低延遲
- 簡化架構
- 節省成本

### 2. 智慧數據傳輸

```javascript
// 小數據（< 8KB）：URL 參數
url?from=extension&job=base64EncodedData

// 大數據（> 8KB）：localStorage
localStorage.setItem('jobbeagle_job_xxx', data)
url?from=extension&jobId=xxx
```

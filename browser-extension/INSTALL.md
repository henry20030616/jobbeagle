# JobBeagle 瀏覽器插件 - 安裝指南

## 📦 安裝步驟

### Chrome 瀏覽器

1. **打開擴充功能頁面**
   - 在網址列輸入：`chrome://extensions/`
   - 或點擊右上角「⋮」→「擴充功能」→「管理擴充功能」

2. **啟用開發人員模式**
   - 點擊右上角的「開發人員模式」開關

3. **載入插件**
   - 點擊左上角的「載入未封裝項目」按鈕
   - 選擇 `jobbeagle/browser-extension` 資料夾
   - 點擊「選擇」

4. **完成！**
   - 你會看到 JobBeagle 插件出現在列表中
   - 點擊右上角的「🧩」圖示，將 JobBeagle 釘選到工具列

### Edge 瀏覽器

1. 在網址列輸入：`edge://extensions/`
2. 開啟「開發人員模式」
3. 點擊「載入解壓縮的擴充功能」
4. 選擇 `browser-extension` 資料夾

---

## 🎯 使用方式

### 方式 1：快捷抓取（推薦）

1. 瀏覽 **104 人力銀行**或 **LinkedIn** 的職缺頁面
2. 點擊瀏覽器工具列的 **JobBeagle 圖示**（🐶）
3. 在彈出視窗中點擊「**📋 抓取職缺並分析**」
4. 插件會自動：
   - ✅ 抓取職缺標題、公司、描述、薪資等資訊
   - ✅ 開啟 JobBeagle 網站
   - ✅ 自動填充職缺描述欄位
5. 你只需要**上傳履歷**，然後點擊分析即可！

### 方式 2：手動複製（原有功能保留）

如果插件抓取失敗，或是其他求職網站，仍可使用原本的方式：
1. 手動複製職缺內容
2. 貼上到 JobBeagle 網站
3. 上傳履歷分析

## 🔧 開發模式設定

如果你在本地開發環境測試插件：

### 修改 `popup.js`

```javascript
// 改為本地端點
const WEBSITE_URL = 'http://localhost:3001';
```

### 重新載入插件

每次修改代碼後：
1. 回到 `chrome://extensions/`
2. 點擊 JobBeagle 插件的「🔄」重新載入按鈕
3. 重新測試

## 🛡️ 隱私與安全

- ✅ 插件**只在職缺頁面**運行（`manifest.json` 限制）
- ✅ **不會收集**個人瀏覽歷史
- ✅ **不會追蹤**你的其他網頁活動
- ✅ 抓取的數據**僅用於 AI 分析**
- ✅ 所有數據通過 **HTTPS 加密傳輸**

### 權限說明

- `activeTab`: 讀取當前標籤頁內容（僅限你主動點擊時）
- `scripting`: 執行抓取腳本
- `host_permissions`: 僅限 104 和 LinkedIn 網域

## 🐛 故障排除

### 問題 1：插件按鈕顯示「請先瀏覽職缺頁面」

**解決方式**：
- 確認你正在瀏覽 104 或 LinkedIn 的**職缺詳情頁**
- 不是搜尋列表頁，而是單一職缺的詳情頁

### 問題 2：抓取的內容不完整

**解決方式**：
- 確保頁面已**完全載入**（包括圖片、動態內容）
- 向下滾動讓所有內容顯示後再抓取
- 如果仍然失敗，可以回到手動複製模式

### 問題 3：無法打開 JobBeagle 網站

**解決方式**：
- 檢查網路連線
- 確認 `popup.js` 中的 `WEBSITE_URL` 設定正確
- 檢查瀏覽器是否阻擋彈出視窗

## 📝 技術細節

### 支援的網站選擇器

**104 人力銀行**：
- 職位標題：`.job-header__title`
- 公司名稱：`.job-header__company-name`
- 薪資範圍：`.job-header__salary`
- 職缺描述：`.job-description`

**LinkedIn**：
- 職位標題：`.job-details-jobs-unified-top-card__job-title`
- 公司名稱：`.job-details-jobs-unified-top-card__company-name`
- 職缺描述：`.jobs-description__content`

如果網站更新了 HTML 結構，可能需要更新 `popup.js` 中的選擇器。
